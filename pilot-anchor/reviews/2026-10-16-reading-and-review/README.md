# はじめに・復習・読む速さの配置（ui25）

本番反映済み。[27ファイルの公開照合](publication.json)、[動作・配置・記録の検査](results.json)、[比較サイトの検査](review-ui-results.json)を参照。iPhone Safari実機は未確認。

[比較ページ](index.html)で33場面を375×700・402×759・440×841の3サイズ、変更前ui24・変更後ui25で比較する。7枚の「はじめに」、読速の説明と4問、復習7問の未選択・誤答・正解を収録する。旧welcome2は新welcome2・3に分割したため同じ変更前画像へ対応し、旧3〜6は新4〜7へ対応する。

時間と回答のペース、順番と休憩を2枚へ分け、元の説明と5つの確認項目を保持する。復習は実際の全問・全状態で最大のBOXを測り、その12px下へ共通ナビを置く。未選択で解説の空白を予約せず、注意文の分だけBOX下端が伸びる。初回と閉じる付き見直しで座標・合格条件・記録と復帰を検査した。

読む速さは説明画面のみBOX化。4問は元の見出しと文章を保ち、番号を見出し横へ移し、本文との54pxの間隔を維持して全体を24px下げる。字数・時間・400msの連打防止・集計・保存再開を変更していない。実アプリの読み取り専用時計probeと本人用操作で記録値も検査した。

`results.json`は同じ27資産を使ったローカル合成セッションの検査。送信試験はlocalhostの模擬同意受け口だけを使用し、参加者データ・本番の収集先へ書き込まない。機種・拡大・touchのガード、座標記録、復習controllerの判定と保存も検査範囲に含む。

`before/capture.json`はui24の撮影元・33場面・99画像を保存した変更前記録。変更前画像は再撮影しない。`build-review.cjs`は旧新27資産・QA・作業版・全画面galleryと画像ハッシュが一致しない場合停止する。再生成は`BEFORE_ROOT`へui24、`AFTER_ROOT`へui25配布一式を指定して実行する。既定のローカル固定コピーは`_work/welcome-details-after`と`_work/reading-review-after`。

全体の現行画面は[画面一覧](../../screen-gallery/index.html)、全説明の固定確認先は[説明レビュー](../2026-10-12-session-explanations/index.html)。
