# 開始前・練習・本番の案内の比較

ui22の採用時点の比較を保持する。後続の変更・現在の公開状況は [ui23](../2026-10-16-intro-cards/index.html)、ui22公開時点の全27配布ファイルの一致は [公開照合](publication.json)、動作・保存機能の確認範囲は [回帰確認](regression.json)を参照する。実機Safariでの確認は未実施。

`index.html` で、対象の表示領域375×700・402×759・440×841の変更前後を切り替える。画像は各サイズの実際のアプリを撮影したもので、画像内のボタンは動かない。

- 最初の6枚：固定BOXとナビ、手順とデータ用途の整理。
- 練習の操作確認：3種類と同時に該当する場合。
- 本番の注意：開始が早い場合・枠を出るまで3秒を超えた場合・両方の場合。
- 練習完了・休憩：説明BOX、本人による次への進行。

変更前は`_work/quiz-box-after/`のui21固定コピー、変更後は`_work/session-guidance-after/`のui22固定コピーを撮影元とする。復習BOXの変更自体は前後の両方に適用済みで、[別の比較ページ](../2026-10-16-quiz-box/index.html)で確認する。

`results.json` は`test-session-guidance.cjs`による変更後の動作・確認記録・休憩・保存復帰・電子同意の検査。`before/capture.json` は旧版の撮影元・画像一覧・通信/例外の記録。旧版の撮影時に新UI専用の文言・固定座標の基準は適用しない。

`review-data.js` は両方の固定コピーから抽出した画面本文と、変更理由・維持条件。`build-review.cjs`で更新する。`review.css`/`review.js`は比較ページ専用で、本番アプリには読み込まれない。

撮影・動作検査は架空データと一時的なlocalhostだけで実施する。参加者原本・本番収集先への通信はない。保存復帰・電子同意検査の模擬POSTはlocalhost受け口のみ。Chromeのタッチ操作エミュレーションであり、iPhone Safari実機確認とは区別する。

公開は本番アプリへの反映と同じ作業で行うが、この比較ページ自体に参加者データの送信先はない。ページのCSPは`connect-src 'none'`を指定している。

公開後の138ファイル一致とPC・スマートフォン幅での36画面切替の確認は [公開サイト検査](published-site-check.json) に記録する。
