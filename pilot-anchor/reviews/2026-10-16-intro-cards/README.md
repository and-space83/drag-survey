# はじめに・操作の確認・同意と追加10問の比較（ui23）

本番反映済み。[全27ファイルの公開照合](publication.json)と[回帰確認の範囲](regression.json)、[比較サイトの操作検査](review-ui-results.json)を参照する。実機Safariの確認は未実施。

[比較ページ](index.html)で20場面を375×700・402×759・440×841の3サイズ、変更前ui22・変更後ui23で見比べられる。画像は合成データによる実際のアプリの撮影で、画像内のボタンは操作できない。iPhone Safari実機の確認とは区別する。

- 「はじめに」：共通タイトルと6つの丸ぽち。BOXの中心とナビの縦位置をそろえ、本文量に応じて高さを変える。初回の「次へ」だけ中央。
- 操作のポイントの確認：練習と本番を同じタイトル・カードの見た目にする。重複する3秒の文を除き、「3秒は回答の制限時間ではありません。自分のペースで焦らず進めてください。」へ変更。
- 同意：画面見出しだけを「研究への参加の同意」に変更。保存する研究説明と協力承諾書の全文・版は変更しない。
- 追加10問：元の本文・強調を保って説明BOXに入れる。

練習のチェック、本番の1つの確認ボタン、注意の回数上限、保存・再開・同意の条件を維持する。枠を出る3秒の対象区間は前のルール説明と復習に残る。

`results.json`は実アプリの操作・進行・保存復帰、`round4-results.json`は実タッチと注意上限の回帰。`before/capture.json`はui22の既存撮影結果と全27資産が一致することを確認して取り込んだ比較基準。`build-review.cjs`は前後の配布資産・最新QA・前画像のハッシュ・画像の参照を照合し、不一致なら停止する。変更前の画像は再生成しない。

再生成は`BEFORE_ROOT`にui22配布一式、`AFTER_ROOT`にui23配布一式を指定し、`node build-review.cjs`を実行する。既定のローカル固定コピーは`_work/session-guidance-after`と`_work/intro-cards-after`。

最新の全画面は [画面一覧](../../screen-gallery/index.html)、全説明の固定確認先は [説明レビュー](../2026-10-12-session-explanations/index.html)。
