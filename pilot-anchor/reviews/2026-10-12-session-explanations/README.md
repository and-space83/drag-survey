# 固定URLの説明・問題レビュー

この資料は、本番の説明・例題・練習問題を画面と実際の文言で確認するためのものです。2026-10-15の全面刷新では、新しい操作説明14状態、復習7問、振り返り4画面と練習導入を追加しました。

変更前の `before/` と過去の承認・廃止の履歴は保ちます。新設・分割した独立画面には「変更前画像なし」と記録します。旧比較IDのうち新画面へ対応させた5件は、対応する `sourceStepId` と説明範囲の違いを明記しています。

撮影はChromeのタッチ画面エミュレーションで、375×548・375×700・402×759・768×1024を対象にします。通常の動きを表示する `no-preference` で見本の途中を撮影し、`motionPreference` を対応表へ残します。静止画像は動きの1場面です。経路の変化と動作の分かりやすさは実際のアプリでも確認してください。Safari実機の操作・拡大防止や、正式な最短待機・保存・再開・送信互換を、この画像確認だけで合格とは扱いません。

## 更新方法

本番ソースの編集が止まった時点で、`tools/pilot-anchor/refresh-explanation-review.cjs` を実行します。Playwrightの場所を `PLAYWRIGHT_MODULE`、必要ならChromeを `CHROME_PATH` で指定します。`REVIEW_WORK_DIR` で作業用撮影の出力先を変更できます。

- 通常実行: 撮影・操作の確認 → ソース一致 → 共有ルールの意味の確認 → 現行画像とHTML生成 → ギャラリー検査。
- `--check`: 保存済みの画像ハッシュ・ソース・全文・寸法・リンク・レイアウトだけを再確認。
- `--from <撮影フォルダ>`: 同じソースで撮影済みの `results.json` と画像から再生成。
- `--from <全撮影> --overlay <部分撮影>`: 本番14資産・寸法・motion設定が一致する場合だけ、同じ名前の画像と確認を再検証結果へ置換。対象外の失敗、実行/通信エラーがある場合は拒否し、置換前の失敗と再撮影範囲を `partialRecaptures` に残す。

操作説明はステップIDで巡回し、自分で動かす画面の成功が必要なことと、復習7問それぞれの誤答による停止・正答による進行を確認します。正式練習後の確認と復習7問は別機能です。元の例題・練習5問・評定・注意・本番・事後アンケートの巡回も保ちます。撮影時は最短待機を省略しており、その待機時間自体の試験結果にはしません。

長いフォームは一画面への収まりを要求せず、横はみ出しがないこと、スクロールが働くこと、末尾の入力やCTAへ到達できること、末尾の入力が固定ナビに隠れないことを確認し、スクロール前後を撮影します。`test-screen-layout.cjs` の `LAYOUT_CASES=post,reading,legacy-blockintro` などで対象を絞った確認もできますが、その部分結果から固定レビューを置換することはできません。

拡大図では透明な入口anchorの文字が `scrollHeight` に含まれ、指のためのcanvasにも空白余白があります。非表示の寸法差は記録に残し、caption・選択肢・canvasの画面境界と、指の可視ピクセルの範囲・canvas端での切れを検査します。説明箱・ナビとの非重なりは、選択肢と描画された指の範囲で判定します。

`layout-results.json` が撮影と操作、`gallery-results.json` が資料の検査、`copy-manifest.json` が文言・画像・版の対応です。公開との一致が未確認なら公開済みと表示せず、過去版の実機確認を今回の全画面確認へ流用しません。本番刷新の前後を実際に操作する比較と実機チェックリストは、`../2026-10-15-guided-release/` にあります。

`validate-capture-overlay.cjs` は異なるソース・寸法・対象外の失敗がある部分結果を拒否し、入力の全撮影結果を書き換えない3検査です。実行結果は `overlay-guard-results.json` に残します。
