## 撮影と再生成

Node.js・Playwright・Chromeを使う。`PLAYWRIGHT_MODULE`を指定すると既定のモジュール読み込みを置き換えられる。合成データのみ使用し、本番への通信は遮断する。保存や送信の成功・失敗はローカルで再現する。状態を注入した画面はmanifestの到達方法に記録する。アプリの原本は変更しない。

```powershell
node tools/pilot-anchor/screen-gallery/capture-flow.cjs
node tools/pilot-anchor/screen-gallery/capture-branches.cjs
node tools/pilot-anchor/screen-gallery/build.cjs
node tools/pilot-anchor/screen-gallery/verify.cjs
```

2つの撮影は独立して実行できる。ビルドは両方の撮影が完了してから行う。撮影中にアプリが変わった場合や、2つの撮影元が違う場合はビルドが停止する。画像欠落・寸法違い・ファイル名重複も停止条件。検証はPC・小画面で、サイズ切替、横並び、検索、画面の拡大、前後移動、画像・アンカーの整合を確認する。

別の作業がアプリを更新している場合は、配布ファイル一式を作業用フォルダに固定し、撮影とビルドの両方へ `APP_ROOT` でその絶対パスを指定する。異なる版の撮影を混ぜない。生成時のローカル実装との一致は `sourceMatchesWorkingTree` に記録し、不一致ならサイトにも撮影元の版を掲載している旨を表示する。

各画像は375×700、402×759、440×841 CSS pxのChromeで撮影する（ガード再現時などの寸法例外は各画像に記録）。CSSピクセルと画像ピクセルを対応させるためDPRは1。Safariのバー・セーフエリアを実機再現したものではない。電子同意の合成氏名は撮影専用。実際の研究参加者データを入力しない。

既存の説明変更レビューの固定URLは [説明の全変更と現行画面](../reviews/2026-10-12-session-explanations/index.html) のまま保持する。このサイトは3端末の順路比較用で、変更前後レビューを置き換えない。

## 本番との照合と画面更新

`node tools/pilot-anchor/screen-gallery/check-public.cjs` で、通常の本番URLから `source-assets.cjs` が列挙する配布ファイル一式（分割した `js/`・`css/` とWorker依存を含む）を取得し、撮影元と照合する。保存・送信中の注意文の改行と全文太字も検査し、`data/publication.json` に結果を残す。本番へのデータ送信は行わない。全ソースの一致を確認した結果だけを、ビルド時にサイトへ表示する。

今回の画面変更・再撮影と廃止表示の対応は [画面更新記録](data/update-summary.json) を参照する。説明本文や研究設計の正本はアプリと研究文書のままとし、この記録は画面確認資料の更新範囲を示す。
